# Crypto Wallet

Мобильное приложение для контроля и анализа криптовалют, реализовано на Swift (UIKit, MVVM+Coordinator).

Реализован подъем текстовых полей и кнопки при появлении клавиатуры. Информация о статусе пользователя (зарегистрирован/незарегистрирова) сохраняется в UserDefaults для корректного рутового VC при новом запуске приложения.

## Особенности реализации

Архитектрура MVVM позволяет разделить слой бизнес-логики и представления, а также удобнен для дальнейшего расширения проекта. Навигация в проекте реализуется с помощью паттерна Coordiantor. Для удобной и наглядной верстки элментов была подключена библиотека SnapKit. Настройка UI реализована без использования Storyboard.
